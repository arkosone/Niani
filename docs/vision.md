## III. Technical Architecture

### A. Photonic Substrate (100% Light-Based)

**No electronics in computing core** (only interfaces if absolutely necessary).

**Why photonics over electronics?**
```
┌─────────────────────┬──────────────────┬─────────────────┐
│ Property            │ Electronics      │ Photonics       │
├─────────────────────┼──────────────────┼─────────────────┤
│ Signal carrier      │ Electrons        │ Photons         │
│ Speed               │ ~10⁸ m/s (Cu)    │ 3×10⁸ m/s       │
│ Parallelism         │ Limited (wires)  │ Massive (WDM)   │
│ Heat generation     │ Significant      │ Minimal         │
│ Interference        │ Crosstalk issues │ Wavelength-safe │
│ Energy efficiency   │ 50-500W          │ ~20W (goal)     │
│ Nature analog       │ Distant          │ Closer (optics) │
│ Rigidity            │ Binary (0/1)     │ Analog (∞)      │
└─────────────────────┴──────────────────┴─────────────────┘
```

**Photonics = more flexible.**  
And flexibility is what enables education over programming.

---

### B. Core Components

**1. Waveguides (Information Highways)**

- Material: Silicon, Silicon Nitride (SiN)
- Function: Confine and route light
- Analogy: Axons in biological neurons
- Structure: Fixed physical paths (but reconfigurable weights)

**2. Photonic Synapses (Adaptive Connections)**

- Material: Phase-change (GSST, GeSbTe, perovskites)
- Function: Variable transmission based on light exposure
- Learning: Hebbian plasticity (physical state change)
- Memory: Non-volatile (retains state without power)

**3. Optical Neurons (Processing Nodes)**

- Design: Ring resonators + nonlinear materials
- Function: Interference-based computation
- Threshold: Optical activation function
- Emergent: Collective behavior, not programmed

**4. Self-Organizing Topology**

**Key Innovation:**

Unlike fixed architectures, NIANI networks **evolve their own structure**.

**Process:**
```
Phase 1: Dense initial connectivity (80-90% synapses present)
    ↓
Phase 2: Education/exposure (months-years of learning)
    ↓
Phase 3: Pruning (unused connections weaken, ~70% eliminated)
    ↓
Phase 4: Optimized topology (unique to this NIANI's experience)
```

**Result:**  
Each NIANI develops a unique "brain structure" based on what it learned.  
No two NIANIs identical—authentic personality emerges.

**Biological parallel:**  
Infant brains have 2× adult synapses, pruned through experience.  
NIANI does the same, but in photonics.

### B. Hebbian Plasticity (Photonic)

**Biological principle:** "Neurons that fire together, wire together"

**Photonic implementation:**
```
Two light signals arrive at synapse simultaneously
    ↓
Interference pattern detected by phase-change material
    ↓
Material heats slightly (optical absorption)
    ↓
Phase transition occurs (amorphous ↔ crystalline)
    ↓
Transmission coefficient changes (synapse strengthened/weakened)
    ↓
Future signals take new path (learning complete)
```

**This is physical learning—not software simulation of learning.**

The material itself IS the memory, IS the adaptation, IS the intelligence.

**What Niani represented:**
- **Scholarship:** Libraries, universities, intellectual exchange
- **Trade:** Gold, salt, and knowledge flowed through the city

- **Legacy:** Timbuktu, Djenné—centers of Islamic learning and science

**At its peak:**
- Mansa Musa's pilgrimage (1324) showcased Mali's wealth
- Scholars from across Africa and Middle East converged
- Mathematics, astronomy, medicine flourished
